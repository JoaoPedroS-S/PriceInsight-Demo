# PriceInsight — Versão Demonstrativa

Sistema web desenvolvido para organizar informações sobre produtos, mercados e preços, auxiliando na consulta e análise de valores praticados por diferentes estabelecimentos.

## Objetivo

O PriceInsight tem como finalidade facilitar a organização e a análise de preços, permitindo identificar possíveis promoções e oportunidades de economia.

## Funcionalidades demonstradas

- Cadastro e consulta de produtos;
- Cadastro e consulta de mercados;
- Registro de preços;
- Identificação de possíveis promoções;
- Filtros e ordenação de ofertas;
- Visualização da localização dos mercados;
- Autenticação de usuários.

## Tecnologias utilizadas

**Frontend:** React, TypeScript, JavaScript, HTML5, CSS3 e Tailwind CSS.

**Backend:** Java 21 e Spring Boot.

**Banco de dados:** PostgreSQL.

**Ferramentas:** Git, GitHub, Jira e Visual Studio Code.

## Arquitetura

O projeto utiliza uma estrutura dividida entre frontend e backend, com comunicação por meio de APIs REST e persistência de dados em banco relacional.

## Sobre esta versão

Este repositório apresenta uma demonstração do PriceInsight, com documentação, capturas de tela e exemplos selecionados de código. Ele não contém a implementação completa do sistema.
